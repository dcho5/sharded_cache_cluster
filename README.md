# Distributed Systems Starter Projects

| Project | What it teaches | Stack | Demo |
|---|---|---|---|
| `raft-kv/` | Leader election, replication, fault tolerance | Go + Docker Compose | `docker compose up`, then `docker kill` the leader |
| `ring-sim/` | Consistent hashing, quorums, gossip, partitions | Vite + TypeScript | Static site, deploy to GitHub Pages |

Each folder has its own README with a TODO checklist. Search for `TODO` in the code to find where to start.
